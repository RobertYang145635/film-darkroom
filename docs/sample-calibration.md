## 调参依据与已知偏差

- 目前未做任何先验调参（P0-C 才开始，且只用 calibration 卷）。
- 已知偏差：整改前自动管线对 G200-1 输出倒置、含片边、偏青蓝、冲淡
  （`质量审查报告.md` F-1；该图列为整改前失败基线）。
- Dmax 用逐帧内容分位估计是"冲淡"的机理之一（亮场景帧估出 1.15，
  远低于胶片能力 ~2.0+）——P0-C 改为胶片/设备先验 + 帧统计仅作下界。

## 缺口（阻断相应支持声明，见 docs/support-matrix.md）

1. **黑白负片：0 张** -> 不得宣称支持。
2. **可解码 ECN-2：0 张**（72 张 AV1 NEF 不支持）-> 需用户用 NX Studio 转
   16 位线性 TIFF（或相机改无损压缩重拍）。
3. **真实 16 位 TIFF / DNG：0 张** -> 扫描仪路线未验证。
4. **第二套设备/光源：0** -> 一切跨设备结论未验证（§12 末段）。
5. **灰卡/色卡样片：0** -> 中性区 ΔE2000≤5 验收无法执行；
   请提供含色卡的样片，或在 GUI 对已知中性区人工取点后导出旁车。

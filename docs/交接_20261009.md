## 3. 已经否掉的路 —— 别再走一遍

1. **无监督"密度去相关"矩阵**（`fixtures/models/generic-color-negative-v1`）：
   实测让颜色**更差**（\|色相角差\| 50.9°→90.4°、四统计距离 0.0905→0.1816，逐帧全差）。
   机理：白化抹掉的是**场景本身**的三通道相关，色罩与景物在同一个协方差里不可分。
2. **"按亮度分带的色相角差"当验收量/拟合目标**：没过自检——同一帧只换取样窗口，
   自身极差中位就有 **26.8°**，而"我方 vs 参考"是 55.2°；同卷同片基的两帧在同一亮度带
   能差 100°。它量的是**内容**。为此写好的 6 参数矩阵拟合脚本
   （`tmp_matrix_fit.py`）**故意没跑**，跑了就是拟合噪声。
3. **摘自动白平衡 / 通道指数来治偏色**：生产解析结果里它们本来就是
   `wb_high=wb_low=(1,1,1)`、`red/blue_ratio=1.0`、`reference_exponent=1.0`，
   摘掉实测影响 **0.0°**。
4. **候选层（preserve/neutral/warm）是偏色来源**：排除。三者与参考的色度向量差
   0.0506 / 0.0512 / 0.0416，而 `preserve` 的 temperature/tint 就是 0 也照样偏。
5. **`red_ratio` 往上调解颜色**：无效。1.3/1.6/2.0 时蓝偏只从 −0.0288 动到
   −0.0260/−0.0232/−0.0220，而饱和偏差崩到 −0.070/−0.105/−0.120。
6. **斜率上限外推**（`MAX_SLOPE=1.6`）、**内容高分位估片基**：都实测否掉，
   见 B-11 追加⑨/⑩⑪。
7. **按 `capture_fingerprint` 自动选胶片 profile**：不可行——`1298_G200`、`1299_G200`、
   `1300_CN400` 三卷指纹**完全相同**（同一台 Z 8 同一组参数），而 Gold200 与 CN400
   是两种片。缺的是**片种判别**，不是相机判别。

## 6. 我这几轮实际犯的方法错误（防重蹈）

1. **把补丁写成"生成 python 脚本再执行"，连续 3 次因嵌套引号/换行在解析期失败**（幸而闸门让改动零落盘）。
   含引号或换行的补丁**必须**走结构化 `edit` 调用。
2. **用行列切片批量改多行调用点**，把 `service.py` 改坏过一次（签名删了、11 处调用点还在传）→ 回滚 + 重跑 409。
3. **一条 edit 因缩进不符静默没落地**，我误以为生效 → 拾点守卫成了哑弹，靠 grep 复核才发现。
4. **把"工具没有 model 参数"推成"所有子代理同模型"**：从"我的选择权"推"系统的事实"。
5. **在 JS 里写 `//`、在 Python 里写 `//`**：3 次把注释符混进错误语言，2 次造成 SyntaxError/非法字符。
6. 两次差点交出"未验证就声称完成"的结果。所有"完成"都以 §1 那两条命令的实测输出为准。

# 快速上手（negative-lab v0.1）

## 启动
双击 `negative-lab.exe`（解压后的文件夹内）。默认完全离线，不上传任何图像。

## 单张处理
1. **打开文件…**：支持相机 RAW（NEF 等）、16 位 TIFF、DNG。
   读取失败会给出文件路径、原因和建议。
2. 画面显示原负片 + 自动检测框：**蓝框=胶片帧**，**黄框=片基取样条**。
3. 点 **自动转换**：去色罩 + 反相，右侧显示参数与置信度，下方列出全部警告。
4. 结果不满意时：
   - 拖动黄框到真正的未曝光片基上 → 点 **用当前片基框重新估计 Dmin**；
   - 点 **取亮部中性点 / 取暗部中性点** 后在画面里点一个应为中性灰的位置
     （如白墙、灰卡、天空），自动重算白平衡与幂指数；
   - 右侧滑块按技术顺序分组：Dmin → Dmax/offset → 白平衡/幂指数 → 黑位/伽马/高光。
5. **导出**：生成 `<原名>-positive.tif`（16 位）+ `.jpg`（**固定 8 位**）+
   `.negative.json` 旁车（完整参数与哈希，可追溯）。**原始文件永不覆盖**。

## 批处理
点 **批处理…** → 选文件夹 →（可选）选配置文件作先验 → 开始。
每张图独立分析；队列显示 ✓/⚠//⊘；失败项可单独重试；取消不留半成品；
结果在 `<文件夹>/negative-lab-out/batch-report.json`。

## 除尘/划痕
- **画笔涂蒙版**：在预览上涂红色区域（负片域修复，反相前），勾选
  **启用除尘修复** 生效；取消勾选 = 完全回退。
- **自动检测(保守)**：只在片基等均匀条带内找孤立尘点；画面内容区
  自动检测容易误伤细节，请手动涂。

## 常见问题
- **黑位发灰/整体灰**：offset 拉太低——把 offset 滑块上调，或确认黄框
  确实在未曝光片基上。
- **高光死白**：Dmax 偏小——增大 Dmax，或启用第 5 组"高光压缩"。
- **NEF 打不开（Z8 高效压缩）**：用 NX Studio 导出 16 位 TIFF 再处理。
- **警告"无中性参考"**：自动只靠片基去色罩，肤色可能偏色——取两个中性点即可。

## 便携与卸载
绿色便携：整个 `negative-lab` 文件夹拷走即可；删除文件夹即卸载。
配置文件在 `%APPDATA%\negative-lab\profiles\`。
Qt(LGPL) 组件为独立 DLL，可自行替换；许可证清单见文件夹内 `docs/`。

# 快速上手（negative-lab v6）

一款离线、无订阅、**不需要色卡**的胶片负片转换工具。
主工作区是**一个**工作区：中央常驻图像，右侧面板分 **分析** 与 **调整**
两个阶段（Lightroom 式 Convert/Edit 模型，v6 单工作区，不再有 v5 的
「裁切页 / 转换页」两个一级页面）。

## 启动

双击 `negative-lab.exe`（或运行 `.venv\Scripts\python.exe -m negative_lab.app`）。
默认完全离线，不上传任何图像。

## 1. 导入与分卷

1. 点 **导入文件夹…**：一个文件夹里可以混着 RAW、16 位 TIFF、DNG、多卷胶片。
   底部胶片条点击切换帧。
2. 左侧是卷列表与缩略图。用 **新建卷 / 改名 / 拆分** 把文件整理成卷
   （也可以先点 **按目录建议分组** 再手工调整）。
3. 采集指纹由程序自动生成（相机/镜头/解码策略/ICC 等 metadata）。
   同一卷里出现指纹冲突的帧会被标红，用 **拆分** 一键分成不同卷即可，
   不需要你手动管理任何"设备配置文件"。

## 2. 分析阶段（右栏「分析」）

在**原负片**上完成三类区域的框选。每个区域在右栏「分析区」是一行任务
（彩点 + 状态 + 框选/清除按钮）：

| 颜色 | 名称 | 作用 |
|---|---|---|
| 蓝色虚线 | **输出裁切** | 最终构图。可以只含画面，也可以保留片边和齿孔 |
| 绿色实线 | **有效画面** | 自动颜色与质量统计只看这里（排除片边/齿孔/漏光） |
| 黄色虚线 | **片基取样** | 未曝光片基，可以有多个（每次拖动新增） |

- 每个框有 8 个手柄，可整体拖动、边角缩放，自动钳制不出画布；
  同类区域重复拖动 = 替换，Esc 取消，Delete 删除当前对象。
- 方向工具：逆/顺时针 90°、水平镜像、±10° 拉直滑杆、**自动检测全部区域**。
- 「转换设置」节的 **保留片边** 勾选随帧保存：勾选后导出整幅
  （含胶片边框），不勾选则用输出裁切构图。
- 框选与保存随时进行；「确认并保存标注」产生用户签字标注。
- 完成后点 **分析完成，去调整 →** 切换阶段。

## 3. 调整阶段（右栏「调整」）

中央显示**转换结果**（毫秒级即时合成）：

1. **色罩校正** 三选一：**保留氛围 / 中性 / 偏暖**。三个候选共享同一
   技术反相，差别只在颜色起点；按钮悬浮显示自动置信度，低置信度会
   自动回退到保留氛围并说明原因。
2. **基础调整**（Lightroom 式）：色温/色调、曝光、对比度、高光/阴影/
   白色/黑色、自然饱和度/饱和度。拖动实时生效（缓存合成），每项可单独
   重置，可把勾选的项目同步到当前帧/选中帧/整卷。
   所有微调只改变输出，**不改变技术正片**。
3. 顶栏 **按住看原片** 随时对照负片。
4. 缩放：滚轮缩放、平移查看细节（高清分片按需加载当前为关闭状态，
   放大显示的是降采样预览的平滑插值）。

## 4. 中性点救援（一键救回颜色翻车的帧）

自动颜色偶尔会把整帧推向蓝/青或偏暖（尤其是背光不均、片基取样薄弱的卷）。
不用回到滑块硬猜：

1. 在**调整**阶段点 **中性点救援**（右栏「色罩校正」节）；
2. 光标变十字，在画面上点一处**本来应该是中性灰**的地方（灰石头、水泥地、
   阴影里的白墙都行）；可以连续点几次试不同位置；
3. 程序在色温/色调两个自由度上精确求解，把这一点拉回中性，画面毫秒级更新；
4. **撤销拾点**逐级回退；按 **Esc** 退出拾点。

要点与限制（不吹）：

- 只在调整阶段生效。回到「分析」阶段会自动退出拾点——那里显示的是负片，
  拿负片上的灰去解正片颜色没有意义；
- 救援只改**输出用的 RenderIntent**，不改技术正片，也不改密度参数；
- 一次合理救援可能吃掉大半条色温滑杆（刻度不是感知均匀的）。救援之后
  滑杆仍然可以微调，只是"再暖一点点"要挪的格数比你想的少；
- 点在已经烧到纯白或纯黑的区域会提示可信度存疑：那里的通道信息已经丢了。

## 5. 你的改动是怎么保存的（工作草稿 vs 确认基线）

程序区分两份东西，别混淆：

| | 是什么 | 什么时候产生 | 会影响导出吗 |
|---|---|---|---|
| **工作草稿** | 你随手框的三类区域、方向、保留片边、微调 | 每次松手自动写盘（不用点保存） | 会 |
| **确认标注（基线）** | 你点 **确认并保存标注** 签过字的标定 | 只有你点确认时 | 会（作为权威基线） |

规则（v6.2 §5.2，避免"草稿悄悄覆盖了签过字的标定"）：

- 只有草稿 → 草稿生效，状态仍是"未确认"；
- 只有确认标注 → 确认基线生效；
- 两者都有，且草稿是在**当前这版基线**上做的 → 草稿生效（它就是你的后续工作）；
- 两者都有，但草稿说不出它基于哪版基线（旧版本留下的草稿）或基线后来变了
  → 判为**冲突**：按确认基线导出，草稿原地保留不删，底部黄条提示你重新确认。
  程序绝不把两份悄悄合并。

重启后草稿自动回到原来的位置（草稿目录随程序设置，测试与冒烟一律写到别处，
不会污染你的真实工作稿）。

## 6. 整卷导出

点 **整卷导出…** → 选择目录 → 再点一次可**取消**（当前帧完成后停止）。
每帧生成
`<原名>-positive.tif`（16 位）+ `.jpg`（固定 8 位）+ `.negative.json` 旁车，
外加 `roll-report.json` 批次报告。写入是事务式的：失败自动回滚，不留半成品；
**原始文件永不覆盖**。状态为"待复核"的帧照常导出，只是提醒你检查。
导出启动那一刻就冻结了所有帧的几何与微调：导出进行中继续编辑/切帧，
不影响本次成片（下次导出才会用新改动）。

## 命令行

```powershell
.venv\Scripts\python.exe -m negative_lab.cli import <文件夹> -o session.json
.venv\Scripts\python.exe -m negative_lab.cli invert <文件> -o <输出目录> `
    --output-crop y0 x0 y1 x1 --image-area y0 x0 y1 x1 --base-sample y0 x0 y1 x1
.venv\Scripts\python.exe -m negative_lab.cli roll --session session.json --roll <卷> -o <输出目录>
```

## 常见问题

- **没有色卡能用吗？** 能。颜色起点来自片基与卷级统计，缺色卡只影响
  提示信息，绝不阻断预览或导出；也不要求先提供胶片型号或相机/扫描仪 profile。
- **提示"待复核"是什么意思？** 程序用了回退（如本帧无片基，借用同卷
  其他帧的卷级模型，或整卷都不可用时的通用先验）。每条提示都会写明
  实际采用了什么回退；你可以直接导出，也可以先微调。
- **某帧颜色和同卷其他帧不一致？** 检查是否混入了不同背光/曝光的帧，
  用 **拆分** 分卷后各自转换；单帧翻车用上面第 4 节的 **中性点救援**。
- **改了「有效画面」框为什么转圈重算，改「输出裁切」却秒回？** 有效画面框和
  片基取样框决定统计范围，必须重算；输出裁切只决定构图，走即时合成。
- **底部黄条说"工作草稿缺少当前确认基线的指纹"？** 说明这个草稿是旧版本写的，
  程序无法证明它基于哪版标定，因此按你签过字的基线导出。想继续那份草稿就
  重新确认一次，之后草稿就会带上基线身份。
- **NEF 打不开（Z8 高效压缩）？** LibRaw 暂不支持，用相机厂商工具导出
  16 位 TIFF 后导入（本软件的 ECN-2 样卷就是这条路线）。
- **想找回 Dmin/Dmax 这些滑块？** 那是研发参数，普通流程不需要；
  CLI 的 `--params` 与研发 API 仍可用。

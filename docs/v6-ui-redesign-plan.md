## 1. 调研结论（同类软件实际布局）

### 1.1 Adobe Lightroom Classic「修改照片/Develop」模块
单页工作区，五个固定区域，**没有模式切换**：

```
+------------------------------------------------------------------+
| 顶栏: 身份牌(左) | 模块选择器(图库/修改照片/...) | (右)            |
+----------+----------------------------------------+-------------+
| 左栏     |                                        | 右栏        |
| 导航器   |        照片（始终是"修改后"的效果）      | 直方图      |
| 预设     |                                        | 基本面板:   |
| 快照     |   裁切激活时: 框外压暗+手柄+三分线       |  白平衡     |
| 历史     |   （照片永远是处理后的正片，             |  色调曲线   |
| 集合     |     从不显示"原始负片"）                 |  HSL       |
| 文件夹   |                                        |  颜色分级  |
+----------+----------------------------------------+-------------+
| 底栏: 胶片条（当前文件夹/集合的水平缩略图，点击切换）               |
+------------------------------------------------------------------+
| 状态: 评分/旗标/缩放/前后对比                                      |
+------------------------------------------------------------------+
```

关键事实：
- **裁切是右栏"基本面板"上方的一个工具按钮**（快捷键 R）。激活后照片上
  出现裁切框+框外压暗，右栏顶部变成裁切参数（比例锁定/角度/拉直），
  面板其余部分仍在。**不换页、不换面板、照片不消失**。
- 所有滑杆改动**实时**反映在照片上（拖动中就在变）。
- "看原图"是按住 `\` 键的临时 before/after，不是常驻状态。

### 1.2 Negative Lab Pro（NLP）
NLP 是**插件**，寄生在 Lightroom 里：它的独立界面只做"转换"这一步
（选胶片类型/边框/每帧设置 → Convert），转换完成后回到 Lightroom 用
标准修改照片面板做后续调整。对本项目的启示：**负片特有的设置要少而
集中**（片基来源、三候选、基础微调），不要发明一套自己的复杂布局。

### 1.3 darktable（暗房模式）
与 Lightroom 同构：中央图 + 右侧处理模块堆栈 + 左侧导入/集合 + 底部
胶片条。深色主题。印证了"单工作区 + 右侧模块堆栈"是这类软件的通用解。

### 1.4 FilmLab / Filmomat SmartConvert
更简单：中央图 + 少量控件（胶片型号/反转为正/白平衡滑杆）。验证了
"控件越少越好，图是主角"。

## 2. 重做目标布局（照搬 Lightroom 骨架）

```
+------------------------------------------------------------------------+
| 顶栏 44px: [导入] [导出] [确认标注]        当前帧名/状态        [设置]   |
+-----------+----------------------------------------------+-------------+
| 左栏 220  |                                              | 右栏 300    |
|           |                                              |             |
| 卷        |         中央：处理后的正片（常驻）             | [直方图占位] |
|  (列表)   |                                              |             |
|           |   裁切工具激活时：框外压暗 + 8 手柄 + 三分线   | ▸ 裁切与几何 |
| 当前卷帧  |   （正常时：整幅正片，无框无压暗）             | ▸ 白平衡     |
|  (列表)   |                                              | ▸ 影调       |
|           |                                              | ▸ 色彩       |
|           |                                              | ▸ 候选起点    |
+-----------+----------------------------------------------+-------------+
| 胶片条 96px: 当前卷水平缩略图（点击切帧，当前帧高亮）                    |
+------------------------------------------------------------------------+
| 状态行 24px: 帧名/尺寸/保存状态 | 轻提示（inline，不弹窗）               |
+------------------------------------------------------------------------+
```

### 2.1 右栏「裁切与几何」= 小工具节（核心纠偏）
默认**收起为一行**；点"裁切"按钮才展开并进入裁切叠加态：

- 进入：照片上出现输出裁切框（框外压暗 55%）+ 8 手柄 + 三分线，
  有效画面/片基区以细线显示（可单独勾选显隐）；
- 节内参数：比例锁定（自由/3:2/2:3/1:1）、旋转 90×2、镜像、
  细微旋转滑杆、自动检测按钮、"完成/取消"；
- 退出：点"完成"或 Esc → 框外压暗消失，回到整幅正片；
  框选结果**立即**反映为新的正片构图（缓存合成，毫秒级）。
- **不再有"裁切页"**：右栏其他节（白平衡/影调/色彩）在裁切态仍可见可调。

### 2.2 右栏其余节（全部实时）
- **白平衡**：色温/色调（作用于缓存正片，毫秒级）；
- **影调**：曝光/对比度/高光/阴影/白色/黑色；
- **色彩**：自然饱和度/饱和度；
- **候选起点**：保留氛围/中性/偏暖 三选一（点击=载入该候选的白平衡+微调
  起点并实时应用）；
- **技术信息**（默认折叠）：片基来源、采集指纹、门禁状态、警告——
  不再占用主视野。

### 2.3 左栏 = 素材组织（唯一职责）
- 卷列表（含"未分卷"）；选中卷 → 胶片条与中央帧随之切换；
- 不再放"当前卷帧大网格"（帧导航交给底部胶片条，去重）。

### 2.4 胶片条 = 帧导航（唯一职责）
- 当前卷全部帧；当前帧高亮；点击切帧；拖动边缘可滚动。

### 2.5 顶栏 = 全局动作
导入文件夹 / 导入文件 / 整卷导出 / 确认保存标注（用户签字）
+ 右侧当前帧状态摘要。**不放假模式按钮。**

## 3. 交互模型（本次必须锁死，实施前不再变更）

1. **照片永远是处理后的正片**。看原负片 = "按住看原片"按钮（临时）。
2. **裁切 = 照片上的叠加工具**，由右栏小节按钮激活/退出；
   拖动过程中框外压暗实时跟随（30fps 即时合成，零管线调用）；
   释放即保存草稿。
3. **输出裁切/有效画面改动 → 毫秒级合成**（缓存整幅正片上切窗口）；
   **片基取样区改动 → 后台重算**（唯一慢路径，约 2-3s，有进行中提示）。
4. **滑杆 = 实时**（拖动中即变，松手精修）。
5. 缩放：滚轮缩放、双击/按钮回到适合窗口；切帧自动重置为适合窗口。
6. 任何错误：状态行 inline 提示，永不弹模态框打断调色。

## 4. 视觉（Codex 式克制 + Lightroom 深色）

- **深色主题**（这类软件的事实标准，也符合"看片"需求）：
  背景近黑 `#1E1E1E`，面板 `#252526`，正文 `#D4D4D4`，辅助 `#8A8A8A`，
  分隔线 `#333333`，焦点/当前 `#4C8DFF`（唯一强调色），
  成功/警告/错误仅用于状态语义。
- 无渐变、无彩色大底、无嵌套卡片；分组靠 1px 分隔线 + 节标题；
- 控件：扁平，圆角 ≤4px；滑杆细轨小手柄；字号 12/11px 两级；
- 不用系统默认按钮样式（Windows 默认按钮是"丑"的主要来源），
  全部自定义 QSS；字体 Microsoft YaHei UI / Segoe UI。

## 5. 明确不做（本次范围外）

- 快捷键体系（只留 Esc/Del）；多选批操作；导出对话框重构。
